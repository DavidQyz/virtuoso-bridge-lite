## 二、设计演化时间线(按模块)

### IDAC 电流镜

```
简单两管镜
  → 输出阻抗不足
  → cascode 镜（精度仍差）
  → OTA 反馈 + cascode（regulated cascode）
  → 发现互补开关（5V器件）在低headroom下失效
  → 改用 OTA EN 控制每个 bit cell（无互补开关）
  → 最终：M_BIAS + 每 bit cell 独立 OTA 钳位 drain = V_REF
```

### IDAC 内部 OTA

```
第一版：标准 folded cascode，4 条外部 bias
  → 蒙特卡洛仅 25% 饱和，bias 偏差 10mV 就崩
  → 原因猜测：无 CMFB（但作者自己也不确定）
  → 放弃

第二版（最终版）：
  → PMOS 输入对（因 V_REF=45mV 极低，Wouter 建议）
  → 右侧 PMOS 二极管接法（提升 PSRR，减少 bias 数量）
  → gm/Id 方法 sizing：gain>55dB，GBW=25MHz，CL=50fF
  → 总电流 1.54µA，输入对支路 445nA，右侧 325nA
  → 实测 GBW 正好 25MHz，工艺角通过
```

### 比较器

```
原版（Cesc）→ 加 5V 隔离管（2V INV 可用，速度提升）
  → 加负反馈（把第一个 INV 电位抬到临界点，加速翻转）
  → 发现负反馈产生 ~80µA 静态漏电（PMOS→NMOS 通路）
  → 去掉负反馈，改用非对称 sizing 略微弥补低压延迟
  → 最终：无负反馈，互补开关隔离，几乎纯动态功耗
```

### PI 控制器

```
开环 Error Amp（高增益版）
  → 无法 trade-off：高增益→高负载 overshoot；低增益→低负载响应慢
  → 本质原因：VCDL δt/δVc 随 Vc 非线性变化；采样点离散（比较器翻转时）

改为 PI：R2=1MΩ，gain(P)=40–50（R1=20–25kΩ），f0(I)≈1MHz
  → Cf 初始设计 6.37pF → 调为 100fF → 最终再次调整为几百 fF（以电路图实际值为准）
  → 最终建立时间约 1.6µs，ripple 约 80mV/1µA，功耗约 6µW
```

### Level Shifter

```
原版（Cesc）：上升慢，下降快 → Vgs 长尾，亚阈值区多
  → resize：稍微改善，但不根本

架构换新（论文方案，去掉首尾 INV）：
  → M4 fingers=10（快速拉低 M6 gate）
  → M6 fingers=5（加速上升）
  → M5 fingers=2（补偿下降损失）
  → NMOS stack 降低静态漏电（副作用：上升进一步加速）
  → 最终 Vgs 尖峰干净，最小稳定电流 0.2µA（20µA 的 1%）
```

### VCDL

```
复杂电流镜版本：常态静态电流 ~70µA/cell（×8 = 超大功耗）
  → resize 到 1:8 镜像：降到 ~11µA
  → 最终：返璞归真，纯动态结构，5V 器件（高 Vth，特性接近原版）
  → 静态功耗接近 0
```

### switchV8（整流开关 NMOS）

```
原版：W=40µm×0.6µm → 效率最高，但 Cgg 大，开关功耗 + INV 功耗超大
  → 最终：W=6µm×0.6µm，开关功耗降至 ~1µW，传输效率略降（可接受）
互补 NMOS：低压（<0.5V 供电）时效率提升显著（~2×），高压下差异小
```

### SPI / 数字接口

```
原版：两个 SPI 串联，固定 2ch，一次传全部数据 → 多通道时传输时间太长
  → 新版：可寻址 8ch，11-bit 帧，每次改写 ~1.4µs
  → 支持 8ch × 8SW = 64 节点
  → DFF 替代存储电容（更可靠）
```

## 四、跨模块关键设计决策

1. **PMOS 输入 OTA**：Wouter 建议。因 V_REF=45mV 极低，NMOS 输入需共模偏置，PMOS 输入天然适配低共模电压。
2. **OTA 钳位代替传统电流镜**：让每个 bit cell 的 NMOS drain 精确锁在 45mV，实现低 headroom + 高输出阻抗的统一。
3. **互补 NMOS 整流开关**：低压（<0.5V 供电）时 PMOS 效率急剧下降，NMOS 补充解决效率问题。
4. **静态功耗优化**：系统静态功耗从 ~500µA 压缩，每模块都做了纯动态化或修漏电。
5. **PI 替代开环 Error Amp**：消除静态误差，解决开环 Gain 无法 trade-off 的根本问题。
6. **可寻址 SPI**：从固定 2ch → 8ch，支持 64 节点，每次改写 1.4µs（神经刺激 100µs pulse 绰绰有余）。
